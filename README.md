# Pig Game 🎲

**Auteur : Gouasmia Sifeddine**

## Description

Jeu de dés pour deux joueurs, réalisé en **HTML, CSS et JavaScript** (sans framework).

## Règles du jeu

- À chaque tour, le joueur lance le dé autant de fois qu'il veut.
- Chaque lancer s'ajoute à son score du tour (**Current**).
- Si le dé tombe sur **1**, le score du tour est perdu et c'est au tour de l'autre joueur.
- Le joueur peut **garder (Hold)** son score du tour pour l'ajouter à son score total.
- Le premier joueur qui atteint **100 points** remporte la partie.

## Ce que j'ai pratiqué

- Manipulation du DOM (`querySelector`, `getElementById`, `classList`).
- Gestion des événements (`addEventListener`).
- Gestion de l'état du jeu (scores, joueur actif, fin de partie).

## Lancer le jeu

Ouvre simplement le fichier `index.html` dans ton navigateur.

## Technologies

HTML5 · CSS3 · JavaScript
